STEP 4: DOWNLOAD THE WEBSITE AS A ZIP FILE
 After the invitation is complete, send this message to Claude:
“My wedding invitation website is complete. Now give me the complete website as a downloadable ZIP file. The ZIP file should contain:
               1. index.html – Complete working website.
               2. photos folder – All my uploaded photographs.
               3. song.mp3 – My uploaded music file, if applicable.
Make sure all file names and folder paths are correct. Use relative file paths so the website works properly after uploading to Netlify. Do not leave out any images, music or required files. Test everything and give me the final downloadable ZIP file.”
STEP 5: UPLOAD YOUR WEBSITE TO NETLIFY
                  1. Visit https://www.netlify.com/
                  2. Create a free account.
                  3. Visit https://app.netlify.com/drop
                  4. Upload your ZIP file or extracted website folder.
                  5. Wait for Netlify to publish your website.
                  6. Copy your live website link.
STEP 6: CHANGE YOUR WEBSITE NAME
                  1. Open your Netlify dashboard.
                  2. Open your website project.
                  3. Go to Site Configuration or Project Configuration.
                  4. Select Change Site Name.
                  5. Enter your preferred name.
Example: aarav-weds-ananya
Your website link will look like:
https://aarav-weds-ananya.netlify.app
